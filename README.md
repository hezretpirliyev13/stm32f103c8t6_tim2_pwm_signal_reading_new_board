# stm32f103c8t6_tim2_pwm_signal_reading_based_on_official_board
As Salam alaikum brothers and sisters. i uploaded here stm32f103c8t6 microcontroller PWM signal reading by TIMER2 based on official board GENERIC STM32F1 
Here is board link https://github.com/stm32duino/BoardManagerFiles/raw/main/package_stmicroelectronics_index.json
you can download through that link on arduino ide.  Let me guide you guys how to download board on Arduino IDE
1. Open the Arduino IDE application on you PC/Laptop
2. As you can top right corner there is File->Preferences
3. On appeared window there is written down Additional boards manager URLs and put on there link and save it
4. If your Arduino IDE is <=2.0.x on the left side there are Sketchbook, Board manager, Library manger, Debug, Search and choose board manager and type the search section "STM32" there and will appear STM32 MCU based boards by STMicroelectronics and install that board
5. Attention you need to install STM32CubeProgrammer application on your PC/Laptop 
6. on the "Tools" section please choose "GENERIC STM32F1 Series" and then choose port
7. so, choose the some options on your depending your microcontroller and upload method and etc
8. Hardware connection:
9. Receiver FS-IA6B connection: CH1->PA0-CH4->PA3, GND->GND, 5V->5V
10. Compile the sketch and upload the sketh and open the serial monitor (CTRL+Shift+M)
